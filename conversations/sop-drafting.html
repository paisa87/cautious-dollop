Updating a Lab Procedure Doc with Copilot

ChatGPT / Copilot Teaching Lab & Research January 24, 2026
Context: I needed to update an existing student handout — originally written for the CyVerse-hosted DNA Subway — to reflect the new standalone Blue Line workflow at dnasubway.org. The document covers how BTC181 students analyze rbcL Sanger sequences from SeqStudio to identify unknown plant samples. Rather than rewriting it myself, I pasted the old document into Microsoft Copilot and asked it to do the update. What followed was something I didn't expect: Copilot stopped and asked clarifying questions before writing a single word of the new document. That single exchange saved at least one full revision cycle.

What changed (at a glance)

  • Platform & account model: Uses dnasubway.org (the updated 2.0 site). Students can Continue as Guest but are encouraged to register to save work.
  • Sanger-focused Blue Line: Steps reflect the AB1 upload → trim → pair/edit consensus → align (MUSCLE) → tree (PHYLIP) flow now bundled in Blue Line.
  • In-platform comparisons: If database matches are wanted, students can run BLASTn inside DNA Subway. External NCBI BLAST is no longer required.
  • Exports: Students can export FASTA from Select Data → Download.
  • Phylogenetic diagram: Added steps to produce and download a tree figure from PHYLIP after MUSCLE alignment.

Procedure overview (11 steps)

  1. Open dnasubway.org → Continue as Guest → Blue Line
  2. Barcoding → rbcL (plants) → name project
  3. Upload AB1 files (Sanger)
  4. Sequence Viewer to inspect traces
  5. EDIT → Trimming and Preparing Reads
  6. Pair Sequences (if F/R) → Edit Consensus
  7. Select Data (choose high-quality / consensus sequences)
  8. ANALYZE → MUSCLE (alignment)
  9. ANALYZE → PHYLIP (tree)
  10. (Optional) BLASTn inside Blue Line
  11. Select Data → Download (FASTA export)

What I took away

  • Copilot stopped and asked two targeted clarifying questions before writing anything. This is the behavior I want — it cost one extra exchange and saved at least a full revision cycle because the domain-specific answers (rbcL, AB1, no-BLAST, add phylogenetics) shaped the entire document.
  • The output wasn't a text response — Copilot wrote a Python script using python-docx to programmatically generate a properly formatted Word document. That's a meaningfully different (and more useful) kind of output than a wall of text I'd have to paste somewhere.
  • The 11-step procedure and the Extra section on phylogenetic trees matched what I asked for without needing follow-up edits. I reviewed and accepted it with minor changes.
  • Knowing your domain matters: the clarifications I gave (rbcL is analyzable entirely inside DNA Subway, students start from AB1 not FASTQ) are things the AI couldn't know. The AI's job was to structure and format — mine was to supply the correct context.
  • The produced file is the actual VG008 attachment now in use in BTC181.
